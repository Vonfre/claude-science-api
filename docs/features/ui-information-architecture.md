# 研舟 · SciPort：界面与交互合同

状态：当前
适用范围：v0.9.0 API-only 改版；上游 CSSwitch 的账号与扩展功能不属于本版公开产品界面。

## 信息架构

仅保留两个导航入口：

1. **工作台**：启动台、当前连接、分层运行状态、API 行式列表与批量管理。
2. **偏好设置**：本地代理与 Science 端口、本机目录与 SSH 权限、应用更新、密钥存储说明。

左侧采用窄导航栏；顶部标示本地工作空间。工作台按启动台、模型连接列表、官方能力说明排序。启动台左侧提供启动 / 打开操作，右侧显示当前选择的名称、默认模型与待应用状态；名称和模型使用纯文本，长内容截断并保留 title。当前选择不冒充运行健康；上次应用明确标注“不代表服务运行中”。网关、Science 服务和上游网络在下方独立呈现，停止服务为次要操作。自检和日志收在“诊断与日志”折叠区。操作反馈面板提供固定在报告正文上方的「关闭」文字按钮（带边框、关闭图标与 Esc 提示）；长报告仅正文滚动。关闭只隐藏反馈，不取消后台操作、不停止服务、不清空结果；后续新结果可以重新显示。存在打开的确认对话框时，Esc 优先交给对话框。

## 名称、外观与退役功能

显示名称为 **研舟 · SciPort**，HTML 标题与原生窗口标题一致；安装包名为 SciPort，bundle identifier、数据目录、IPC 名称与主题存储键保持兼容。

浅色为雾白底、浅色窄导航和深绿色启动区；深色共享同一套语义色变量。品牌图形为本地内联 SVG，不下载字体、图片或其他视觉依赖。主题切换保留图标，更新文字与可访问名称。

Science 页面中文切换已退役：删除前端开关与控制器、词典与浏览器扩展源码、插件导出命令、语言偏好 IPC 和 native-host CLI。不会自动读取、修改或删除用户已导出的插件、浏览器注册及语言偏好文件；曾安装的扩展需用户自行停用。主窗口 IPC guard 从语言模块保留到 `src-tauri/src/lib.rs::main_window_commands`，继续拒绝非 `main` webview，不能因移除汉化而放宽命令访问范围。

## API 列表与批量管理

一条配置占一行，使用语义化 table，列为：勾选、名称、默认模型、密钥状态、操作。操作统一使用选择 / 编辑 / 更多三个同尺寸图标，提供 title 悬停说明、可访问名称和 aria-pressed 当前状态；不会以颜色作为唯一的选择信号。

- “设为当前”仅保存选择，不立即切换运行中的服务；当前行以绿色底色、侧边标记线和实心绿色勾选图标突出显示；选择尚未应用时单独显示“待应用 · 启动后生效”。批量勾选使用不同颜色，不冒充当前选择。启动 Science 才走原有 apply/start 边界。
- “上次应用”不是运行健康证明；进程是否运行以上方状态为准。
- 名称、模型、模板和备注支持不区分大小写的搜索。列表绝不渲染完整密钥，也不提供含密钥导出。
- 默认没有复选框；用户必须显式进入“批量管理”才能逐项勾选。不提供全选入口，退出批量管理会清空勾选；搜索不会清除其他已选项目，工具栏显式提示隐藏的选择数量。
- 批量删除 / 清除密钥先以 modal 列出目标名称及数量，默认焦点在取消；删除还必须准确输入“删除 N 项”才会开放确认，提交入口重复校验该文字；涉及当前选择或上次应用时说明停止代理的影响。
- `profile-batch.js` 负责纯选择集合操作及顺序批处理；`profile-controller.js` 负责界面、忙碌锁、确认快照及提交后的刷新；原有 Rust mutation owner 仍负责每个项目的提交和恢复。
- 批量操作**不是跨项目原子事务**。逐项调用原有 IPC，严格验证 intent / mutation 结果。首次失败或结果不确定后停止，不自动重试，不回滚已确认完成项目。报告完成数量、未确认项目和未尝试数量。
- 成功项从多选集合中移除；失败和未执行项在重新读取配置后保留仍存在的项目。刷新失败必须明确提示，不能冒充完整成功。

## API-only 边界与兼容

`src-tauri/src/api_only.rs` 负责公开 DTO 的账号配置过滤与 API 准入。前端不挂载 Codex 登录、网络设置、官方模式或 Skill/MCP 管理；对应非 API IPC 不再注册。普通 OpenAI-compatible 第三方 API 仍受支持。

通用元数据编辑、清除密钥、删除入口也拒绝账号配置；缺失 ID 的行为仍由原 mutation owner 决定。显式启动操作允许先重放中断的本地恢复，再检查 API 准入；即使旧当前项被隐藏，恢复入口也不会被前端拦截，恢复完成后仍禁止账号认证和启动。

旧账号配置、存储格式与恢复逻辑保留，避免升级时破坏用户数据；不因读取列表而迁移、删除旧数据或自动选择替代 API。旧官方模式启动应用只打开面板，用户明确选择 API 并启动后才转为第三方模式。

## 状态与安全

- 保存配置、当前选择、上次应用、代理健康与 Science 可访问是不同概念。
- 官方连接器依赖官方账号会话。界面以“能力说明 · 非登录检测”解释第三方模型连接不等于官方授权；不读取官方会话、不伪造登录、不隐藏 Science 的错误，也不宣称修复真实连接器。
- 端口显式保存，必须是 1024–65535 的不同整数；8765 留给用户官方 Science。
- 密钥保存在本机配置中，不宣称为钥匙串加密；界面只显示是否保存。
- API-only UI 不改变后端既有配置事务、恢复、进程隔离与凭证持有责任。
- 浏览器预览显式标记虚拟配置及状态，不连接真实 API，也不启动 Science。模拟 mutation 必须遵循真实 typed outcome，不能仅返回任意“ok”。

## 布局与验证

默认窗口 1180×800，最小 820×600；深浅主题、键盘焦点、减少动态效果偏好均支持。窄窗口仍保持行式列表，必要时仅表格局部水平滚动，不把行重新变成卡片。

行为测试由 `test/sciport_ui.test.mjs`（名称、退役边界、启动摘要与主题）、`test/profile_batch.test.mjs`、模型目录、运行结果协议与预览测试共同覆盖；Rust `ipc_scope_tests` 验证非主窗口命令拒绝。浏览器交互检查、源码测试、App 打包与真实供应商连接是不同证据层；不以预览或编译通过声称真实连接已验证。

运行状态按探测层分别命名：本地代理与 Claude Science 显示健康检查结果，未通过时为「未启动或未就绪」；上游网络仅表示 TCP 端口可达性，绿色显示「网络可达 · API 未验证」，不能作为 API 密钥、模型调用或 Science 运行成功的证据。

## 主目录授权

设置页的“我同意 Science 使用本机真实主目录”默认不勾选，包括旧版升级。用户在
阅读官方启动前可能检查／迁移历史 Science 数据的说明后，主动勾选并保存才授权。
取消勾选并保存即撤销；两种变更都通过既有运行设置事务停止当前服务，重新启动后
生效。读写仍由 Science 授权，不提供全 HOME grant，也不复制官方账号凭据。
持久化、恢复与进程边界以 [Science runtime](../architecture/science-runtime.md) 为准。


## 工作目录与应用更新入口

未授权本机 HOME 时，交互启动先显示目录访问对话框，默认焦点为取消。
同意后保存既有权限配置并继续启动；本次隔离选择不等于持久授权；取消或 Esc
不启动。工作台保留“工作目录权限”入口，设置允许撤销。该入口解释原始
`Directory is not under $HOME or a granted root` 错误，但不承诺 HOME 外目录
自动获权；运行隔离与授权边界见 [Science runtime](../architecture/science-runtime.md)。

应用更新在偏好设置中显示检查结果，发现新版本时工作台出现非模态提示；
自动检查不弹安装确认、不打断工作。点击下载更新先要求用户保存工作并确认，
再走验签、停止服务、安装和重启。取消不调用安装，失败可重试；版本和错误使用
纯文本，后端私有错误不直接呈现。发布附件、签名密钥及升级验收的 owner 是
[发布流程](../operations/release.md#sciport-应用内更新)。
